XP & LEVELING — COMPACT SHEET
Level-Up
XP needed: 1000 * 1.15^(level-1),
Each level requires +15% more XP than the previous,
+1 stat point per level,

Attack XP
Win (Attacker)
Range: 10–200,
Formula: base(100) * levelMod * turns * fortBonus,
Win (Defender)
Range: 1–15,
Formula: 10% of attacker win XP,
Loss (Attacker)
Range: 10 * turns,
Notes: No level modifier,
Loss (Defender)
Range: 1–40,
Formula: 0.25 * attacker win XP * levelMod,

Spy XP
Recon success (spy): 3–66 (1/3 of attack XP values),
Recon success (target): 1–5 (10% of recon base),
Recon fail (spy): ~3 (consolation),
Recon fail (target): 1–13 (caught‑spy bonus),
Sabotage: all recon values ×2,

Level Modifier (levelMod)
Attacking higher level: +10% per level above,
Attacking lower level: –5% per level below,
Minimum modifier: 0.5× (floor),
Examples
3 levels below → 1 - 0.15 = 0.85,
2 levels above → 1 + 0.20 = 1.20,
Anything below 0.5 → clamp to 0.5
